# Promo popup creative

The homepage promo popup (`src/modules/homepage/components/PromoPopup.tsx`)
shows **one image only** — the image is the whole click target and links to
`PROMO_POPUP.href` in `src/modules/homepage/content.ts`.

Drop the creative here with this exact name:

| File                    | Used for          | Links to                                                          |
| ----------------------- | ----------------- | ----------------------------------------------------------------- |
| `sslc-power-guides.png` | SSLC Power Guides | https://studio.parikshe.in/details?nid=4785371&origin=parikshe.in |

Recommended: landscape, ~1600×840 (roughly 16:9), < 300 KB, PNG or JPG.

Until the file is present the popup falls back to a plain branded panel.
